List in HTML

There are two types of lists in HTML:

  • Unordered list
  • Ordered list

An unordered list is a list of items in which the order does not matter. An ordered list is a list of items in which the order does matter.

Unordered List

  • Coffee
  • Tea
  • Milk

Ordered List

  1. Coffee
  2. Tea
  3. Milk
